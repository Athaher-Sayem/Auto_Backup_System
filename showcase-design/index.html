02 / SOURCE NOTE

Two folders.
One intent.

The repository contains Python-version and Bash-version folders. The Bash entrypoint uses Zenity for choices and a tar → pv → gzip pipeline to create a dated archive; restore is delegated to a script. Inspect the source before using either version on real data.

FROM THE BASH ENTRYPOINT / SIMPLIFIEDREAD-ONLY
source config.cfg

# Backup branch
cd "$BACKUP_SRC"
tar -cf - . | pv -n | gzip \
  > "$BACKUP_DEST/desktop_backup_…tar.gz"

# Restore branch
bash scripts/restore.sh

This snippet is an explanatory excerpt, not a runnable command or validation of restore safety.
